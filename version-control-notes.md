1. What is Version Control and Why is it Important?

Version Control is a system that helps developers track changes made to their code over time.
It is important because it helps prevent data loss and makes project management easier.
It allows developers to:
- Track changes in files.
- Restore previous versions of code.
- Work together on the same project.
- Identify who made changes and when.

2. Why Do Developers Use Git?

Git is a popular version control system used by developers to manage and track changes in their projects.
Developers use Git because:
- It tracks code changes.
- It allows multiple developers to work together.
- It helps create different branches for new features.
- It allows developers to go back to previous versions.
- It makes code management easier.

3. What Common Problems Does Git Solve?

Git solves several common development problems:
- Code loss: Developers can recover previous versions.
- Team collaboration:Multiple developers can work on one project.
- Tracking changes:Developers can see what changes were made.
- Code conflicts:Git helps identify conflicting changes.
- Backup:Developers can store copies of their code in remote repositories.

4. Difference Between Git and GitHub

Git: Git is a version control tool that tracks changes in source code.
GitHub:GitHub is an online platform where developers can store Git repositories and collaborate with others.

Example:
Git helps us manage code changes, while GitHub helps us share and manage our code online.

5. Centralized vs Distributed Version Control Systems

Centralized Version Control System (CVCS):**

- Uses one central server to store project files and history.
- Developers need to connect to the central server to access the latest changes.
- Example: SVN (Subversion).

Distributed Version Control System (DVCS):**
- Every developer has a complete copy of the project and its history.
- Developers can work offline.
- Changes can be shared with other developers.
- Example: Git.
